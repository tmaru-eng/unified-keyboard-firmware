# Security policy

## Scope

This policy covers the public source tree, the WebHID configuration UI, and the
published GitHub Pages site. It does not promise a formal security
certification or protect a private development environment.

## Reporting a vulnerability

Please use the repository's **Security** tab and **Report a vulnerability** to
send a private GitHub Security Advisory. Do not publish pairing keys, IRKs, BLE
addresses, browser data, or hardware logs in a public issue or pull request.

If private reporting is not available, open an issue that contains only a
high-level description and ask the maintainer for a private reporting channel.

## Supported versions

Only the default branch and the latest published release are expected to
receive security fixes. Firmware and WebHID behavior must be validated together
when a protocol or device-boundary change is proposed.
